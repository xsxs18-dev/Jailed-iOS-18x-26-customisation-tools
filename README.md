# Jailed iOS 18.x – 26 Customisation Tools

Jailbreaks and other customisation tools that work on iOS 18 to 26. Project links and compatibility notes reviewed against upstream GitHub READMEs on November 12, 2026. Listed version ranges are upstream claims, not independent device testing.

Some tools use kernel exploits or sandbox escapes; others rely on partial backup restore, configuration profiles, Shortcuts, or normal APIs. You can get bootloops, kernel panics or lost app data, and Apple can patch the bug at any time. Back up first and only download from the links below.

## Fake "online jailbreaks"

Be cautious with websites promising a full jailbreak through a configuration profile or alternative app store. These mechanisms alone do not jailbreak iOS. Use official upstream repositories and inspect release assets.


## About the exploit column

Names identify publicly documented techniques; this is not an exploit tutorial. A **sandbox escape** is not the same thing as **kernel read/write** or a full jailbreak. A partial-backup technique is not a kernel exploit. Exact implementation and availability vary by hardware and build. If upstream has not documented an exact vulnerability, the table deliberately uses a broader description rather than inventing a CVE.
